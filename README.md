Tea Quality and Grading System

Project Overview

This project is a Smart Tea Leaf Grading and Quality Control System developed using Machine Learning and Computer Vision techniques. The system predicts whether a tea leaf sample belongs to Group A – Good Quality or Group B – Bad Quality by using measurable visual features such as color, size, and shape.

The main purpose of this project is to reduce subjectivity in manual tea leaf grading and support more consistent quality evaluation.
