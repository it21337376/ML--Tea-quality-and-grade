Smart Tea Leaf Grading and Quality Control System

Project Title

Smart Tea Leaf Grading and Quality Control Using Machine Learning and Computer Vision

---

Project Overview

This project is developed as a part of the Tea Factory Management System using Machine Learning.  
The main focus of this component is Smart Tea Leaf Grading and Quality Control.

The system predicts whether a tea leaf image belongs to:

- Group_A – Good Quality Leaf
- Group_B – Bad Quality Leaf

The model uses image processing techniques to extract measurable visual features such as **color, size, and shape** from tea leaf images. These extracted features are then used as input parameters for a machine learning model to classify the tea leaf quality.

This approach helps reduce subjectivity in manual tea leaf grading and improves grading consistency.

---

Problem Statement

In many tea factories, tea leaf grading is still done manually by workers. Manual grading depends on human experience and visual judgment. Because of this, grading results can vary from person to person.

Manual grading can be affected by:

- Human tiredness
- Lighting conditions
- Different experience levels
- Time pressure
- Personal judgment

As a result, the same tea leaf sample may be graded differently by different workers. Therefore, a machine learning-based approach can support more consistent and objective tea leaf quality evaluation.

---

Research Gap

Tea leaf grading is commonly performed using manual visual inspection. This method can be subjective and inconsistent. Existing approaches may focus on limited features or manual decision-making.

This project addresses the gap by using computer vision to automatically extract color, size, and shape features from tea leaf images and train a machine learning model to classify tea leaf quality.

Objectives

Main Objective

To develop a machine learning-based tea leaf grading system that predicts whether a tea leaf is good or bad using image-based visual features.

Specific Objectives

- To collect tea leaf images and organize them into quality groups.
- To extract color, size, and shape features from tea leaf images.
- To train a machine learning model using the extracted features.
- To classify tea leaves as Group_A or Group_B.
- To evaluate the model using accuracy, classification report, and confusion matrix.
- To support consistent quality evaluation in tea leaf grading.
